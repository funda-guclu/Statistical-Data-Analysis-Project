# Statistical Data Analysis & Hypothesis Testing Project

This repository contains a comprehensive statistical study conducted as part of the **Mathematical Engineering** curriculum at **Yildiz Technical University**. The project focuses on analyzing a population of 200 data points through descriptive statistics, data visualization, and inferential statistical methods.

## 📊 Project Overview

The core of this project is the transformation and analysis of raw data to derive meaningful insights and validate claims using statistical rigor. 

### Key Features & Methodology:

1. **Data Transformation:**
   - Raw population data was personalized using a transformation formula based on student ID: $NewData = RawData + (Last3DigitsOfID + 123)$.
   - This ensured a unique dataset for individual analysis.

2. **Descriptive Statistics:**
   - **Frequency Distribution:** Created frequency tables with specific class intervals.
   - **Central Tendency:** Calculated Mean, Median, and Mode.
   - **Dispersion Measures:** Computed Variance and Standard Deviation to understand data spread.
   - **Distribution Analysis:** Evaluated the symmetry and skewness of the dataset.

3. **Data Visualization:**
   - **Histogram & Frequency Polygon:** Visualized the distribution shape.
   - **Cumulative Frequency Graphs:** Plotted both "more than" and "less than" cumulative ogives on a single chart to analyze data trends.

4. **Inferential Statistics:**
   - **Confidence Intervals:** Established confidence intervals for the population mean ($\mu$) and population variance ($\sigma^2$) at a significance level of $\alpha = 0.08$.
   - **Hypothesis Testing:** - Performed **Z-tests** to evaluate specific population claims.
     - Calculated **P-values** to determine the statistical significance of the results.
